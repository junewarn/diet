# 🥗 科学减脂助手

一个基于 Web 的科学减脂管理工具，帮助您健康、科学地管理体重和饮食。

## ✨ 功能特点

### 👤 个人信息管理
- 记录性别、出生日期、身高、体重
- 设置运动系数（久坐型/轻度/中度/高度运动）
- 设置每周减重目标

### 🔥 热量计算
- 基于 Mifflin-St Jeor 公式计算基础代谢率 (BMR)
- 计算总热量消耗 (TDEE)
- 显示每日摄入热量目标
- 实时显示今日摄入和剩余热量

### 📝 饮食记录
- 支持早餐、午餐、晚餐、加餐记录
- 搜索食物并添加到餐次
- 支持按克或按个添加食物
- 显示每餐的营养信息（热量、碳水、蛋白质、脂肪）
- 支持编辑和删除食物记录

### 📊 饮食历史
- 按月/年查看饮食记录
- 显示每日摄入总热量
- 计算月度/年度热量缺口
- 点击日期可查看详细饮食记录

### 💡 饮食建议
- 根据剩余热量推荐每餐摄入量
- 智能推荐食物搭配
- 基于历史饮食习惯提供建议

### 🍽️ 食物管理
- 添加、编辑、删除食物数据
- 搜索食物功能
- 支持自定义食物营养信息

### 📤 数据导入/导出
- 一键导出所有数据为 JSON 文件
- 支持导入之前导出的数据
- 数据本地持久化存储

## 🔬 科学减脂原理

### 基础代谢率 (BMR) 计算公式
- **男性**: BMR = 10 × 体重(kg) + 6.25 × 身高(cm) - 5 × 年龄 - 161
- **女性**: BMR = 10 × 体重(kg) + 6.25 × 身高(cm) - 5 × 年龄 + 5

### 总热量消耗 (TDEE)
TDEE = BMR × 运动系数

| 运动系数 | 描述 |
|---------|------|
| 1.2 | 久坐型（几乎不运动） |
| 1.375 | 轻度运动（每周1-3次） |
| 1.55 | 中度运动（每周3-5次） |
| 1.725 | 高度运动（每周6-7次） |

### 健康减重建议
- 建议每周减重 0.5-1kg
- 每日热量缺口建议 300-500 kcal
- 每日摄入不应低于基础代谢率

## 🛡️ 健康警告

当您设置的减重目标导致每日摄入热量低于基础代谢率时，系统会发出警告：

⚠️ **低于基础代谢的饮食可能导致：**
- 肌肉流失
- 代谢下降
- 内分泌紊乱

系统会自动建议调整至安全目标，确保您的健康。

## 🚀 快速开始

### 本地运行
```bash
# 克隆仓库
git clone https://github.com/junewarn/diet.git

# 进入项目目录
cd diet

# 使用 Python 启动简易服务器
python3 -m http.server 8000

# 访问 http://localhost:8000
```

### 文件结构
```
diet/
├── index.html        # 主页面（包含所有前端逻辑）
├── food_data.js      # 食物数据加载脚本
├── food_data.json    # 食物营养数据库
└── README.md         # 项目说明文档
```
